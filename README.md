# Bank Loan Performance Dashboard | Excel Portfolio Project
An Excel dashboard project exploring lending activity, borrower characteristics, payments received, and loan status across 38,576 loan records.
Business problem
Lending teams need a consolidated view of application volume, funded amounts, repayment activity, interest rates and loan outcomes. This workbook provides summary and overview dashboards to help explore these measures.
Key metrics
Metric	Workbook value
Loan applications	38,576
Total funded amount	435,757,075
Total payments received	473,070,933
Average interest rate	12.05%
Average DTI	13.33%


Currency and source provenance are not specified in the workbook. Payments received should not be interpreted as profit.
Workbook contents
- Summary Dashboard: portfolio-level KPI dashboard.
- Overview Dashboard: portfolio breakdown dashboard.
- Sheet Design: supporting KPI summaries and calculations.
- financial_loan: 25-column loan-level table with a derived good/bad classification.
Data fields
Loan identifiers, borrower state, employment length, home ownership, loan purpose, grade/sub-grade, status, issue/payment dates, term, income, DTI, installment, interest rate, loan amount, total accounts and total payments. See [project documentation](Bank_Loan_Project_Documentation.docx) for definitions and assumptions.
Tools
Microsoft Excel, formulas, pivot-style summaries, interactive dashboards.
How to explore
1. Open the workbook in desktop Microsoft Excel.
2. View the Summary Dashboard and Overview Dashboard.
3. Explore filters and compare metrics by loan segment.
4. Consult Sheet Design for supporting calculations.
# Limitations and responsible publication
The source, reporting date, currency and licensing terms need confirmation. Verify calculations and classification logic before drawing business conclusions. The raw workbook includes member_id and emp_title, which may contain sensitive or identifying information. Do not publish the raw workbook until you have permission and have reviewed or anonymized the data.
